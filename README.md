# AI 专栏 · 新 AI 时间线

从 2022 年 ChatGPT 到现在，值得知道的 AI 产品按发布时间倒序排列。

在线预览：https://curzydj8.github.io/ai-column/

每个产品都写清：是什么、哪个公司、什么时候发布、免费还是要充值（多少钱）、最适合干什么。支持按分类（聊天对话 / 编程助手 / 图像生成 / 视频生成 / 搜索 / 智能体 / 办公效率 / 语音 / 设计 / 开源模型）和价格（免费 / 免费+订阅 / 付费）筛选。

- 数据：`data.json`（38 个产品，2022-11 至 2026-11）
- 生成：`python3 build.py`（读 data.json 生成 index.html）
- 更新于 2026-11-16；定价为核查时的公开价，以官网为准；标“待核验”的请以官网为准。
